Building a Genie Agent Builder Skill for Genie Code


The Problem

Setting up a Databricks Genie Agent properly is a 10+ step process: schema creation, curated views, metric views, agent creation, instructions, glossary, knowledge snippets, entity matching, column synonyms, benchmarks, and table descriptions. Most teams do this manually, one click at a time — producing inconsistent results and missing critical configuration that tanks answer quality.

What if you could just say "Build a Genie Agent for HEDIS" and get the entire thing — schema to benchmarks — in under 2 minutes?


The Solution: A Genie Code skill

Genie Code supports skills — modular knowledge files that extend Genie Code's domain expertise. When you trigger a skill, Genie Code loads its guidance and follows its operating procedures using the built-in tools (SQL execution, Genie Agent configuration, table introspection, and more).

We built a genie-agent-builder skill that automates the entire Genie Agent lifecycle:

• Inspects source tables (schema, columns, joins, data types)
• Designs a curated analytics layer (views, metric views)
• Creates the Genie Agent with tables attached
• Configures the full instruction set (glossary, SQL examples, knowledge snippets)
• Enables entity matching on categorical columns
• Sets column synonyms for natural-language resolution
• Adds benchmarks for evaluation
• Sets table and column descriptions


What We Built: HEDIS Quality Analytics

Using the skill against catalog_name.hedis_raw (8 raw tables), it produced:

• Curated schema → catalog_name.hedis_curated
• Views → 4 business-friendly views (member_measure_summary, gaps_overview, provider_performance, measure_reference)
• Metric view → hedis_metrics with 10 dimensions + 5 MEASURE() metrics
• Genie Agent → full config: description, scope, glossary, 8 starter questions, 8 SQL examples, 9 knowledge snippets, 30 entity-matched columns, 14 synonym sets, 15 benchmarks

Total time: ~90 seconds from prompt to production-ready agent.

Key files explained:

SKILL.md — the skill's brain. Contains:
• Trigger conditions (when Genie Code loads this skill)
• Operating procedure (the 10-step execution plan)
• Domain reasoning rules (healthcare-specific logic, PHI handling, HEDIS semantics)
• Quality bar (what a good output looks like)
• Response rules (never expose sensitive fields, prefer curated over raw, and more)

references/genie-meta-template.md — the canonical template with 9 phases:
1. Domain understanding
2. Source data inventory
3. Data quality and fitness
4. Business question coverage
5. Curated model design
6. SQL generation
7. Validation with representative questions
8. Genie Agent completion pack
9. Final output format


Installation: How to Add This Skill to Your Workspace

Step 1 — Clone the repository:

  git clone https://github.com/bigdatavik/databricks-genie-agent-builder.git
  cd databricks-genie-agent-builder

Step 2 — Upload to your workspace. The skill must be placed at this exact path:

  /Workspace/Users/<email>/.assistant/skills/genie-agent-builder/

Option A — Databricks UI:
1. Navigate to your workspace home folder
2. Create the directory path .assistant/skills/genie-agent-builder/
3. Upload SKILL.md into that folder
4. Create a references/ subfolder and upload genie-meta-template.md

Option B — Databricks CLI:

  EMAIL="you@company.com"
  DEST="/Workspace/Users/$EMAIL/.assistant/skills/genie-agent-builder"
  databricks workspace import-dir skills/genie-agent-builder "$DEST" --overwrite

Option C — Repos (Git integration):
1. Add the repo as a Databricks Git folder
2. Copy the skills/ directory to your .assistant/ path using a notebook:

  import shutil
  email = "you@company.com"
  src  = f"/Workspace/Repos/{email}/databricks-genie-agent-builder/skills/genie-agent-builder"
  dest = f"/Workspace/Users/{email}/.assistant/skills/genie-agent-builder"
  shutil.copytree(src, dest, dirs_exist_ok=True)

Step 3 — Verify installation. Open Genie Code and type:

  Build a Genie Agent

If the skill is loaded correctly, you'll see the structured input template asking for domain, source schema, and target schema.

Customizing the Skill

You can fork and adapt the skill for your organization:

• Domain-specific rules → SKILL.md, "Step 4 — Apply domain reasoning"
• Naming conventions → SKILL.md, "Step 2 — Normalize the inputs"
• Compliance constraints → SKILL.md, "Operating procedure"
• Output structure → references/genie-meta-template.md, Phase 8–9
• Benchmark count → references/genie-meta-template.md, Phase 7


Tips for Best Results

• Provide clean source tables — the skill is only as good as the raw data. Well-named columns and existing UC comments dramatically improve output quality.
• Specify the domain clearly — "HEDIS quality" produces better reasoning than "healthcare."
• Run benchmarks after build — the 15 auto-generated benchmarks immediately tell you where the agent needs tuning.
• Iterate with feedback — after users interact, use Genie Code's "curate from feedback" capability to extract knowledge from thumbs-up answers and add thumbs-down questions to benchmarks.
